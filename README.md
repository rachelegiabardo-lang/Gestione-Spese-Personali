# Gestione Spese Personali

Sistema di monitoraggio delle spese e gestione dei budget mensili sviluppato in Python e SQLite per l'esame di Fondamenti di Informatica.

## Requisiti per l'esecuzione

Per eseguire il programma è necessario disporre di:

* **Interprete**: Python 3.x
* **Librerie Standard**:
    * `sqlite3`: Gestione del database.
    * `datetime`: Gestione di date e mesi.
    * `os`: Gestione dei file di sistema.

Il progetto non richiede l'installazione di pacchetti esterni perchè utilizza solo moduli di Python.

## Istruzioni per l'esecuzione

Il programma è di tipo interpretato, pertanto non necessita di una fase di compilazione preventiva. Il database SQLite viene generato automaticamente dal codice al primo avvio.

### Avvio del programma

1. Aprire il terminale (o Prompt dei comandi).
2. Posizionarsi nella directory principale del progetto (dove si trova il file `main.py`).
3. Digitare il comando di avvio.

### Comando esatto da eseguire

python main.py
